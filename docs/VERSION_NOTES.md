# Computational version notes

## Package scope

This package contains the public input workbooks, seven analysis scripts, dependency specifications, and workflow documentation for a polyurethane chemical-space study. Intermediate tables and figures are generated locally from the supplied inputs.

## Data organization

The literature workbook collects formulation records reported under different material names, component representations, composition conventions, and measurement conditions. The workflow provides a common tabular representation, component-level structure descriptors, ratio normalization, threshold labels, dimensionality reduction, density-based clustering, and regional scoring. This is a quantitative scheme for organizing heterogeneous literature data and connecting it with a virtual formulation library.

## Computational settings

The dependency versions in `requirements-tested.txt` record the package versions used for the local software checks. The workflow fixes the descriptor columns, UMAP settings, HDBSCAN settings, and scoring constants described in `docs/WORKFLOW.md`. Cluster identifiers are generated by the fitted map and should be read together with the corresponding `Clusters_composition.csv` file.

## Output conventions

Stage outputs are written to `outputs/`: virtual formulations, repaired ratios, descriptor tables, UMAP coordinates, cluster assignments, cluster composition, and regional score tables. A score is a regional ordering statistic derived from the descriptor geometry and literature reference labels. It is intended to support candidate organization and prioritization within the workflow.
